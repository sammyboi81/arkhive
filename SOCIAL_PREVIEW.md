# Social preview specification

- Canvas: 1280×640 px (2:1), with a 1200×600 safe area.
- Background: deep neutral navy or charcoal; no gradients that reduce contrast.
- Primary line: **Humane Intelligence MCP**
- Secondary line: **Persistent, verifiable memory and governance for AI agents**
- Supporting chips: **Local-first** · **Tamper-evident** · **Claude + Codex**
- Visual: a restrained five-link chain or ledger motif; do not use screenshots,
  spiritual imagery, consciousness claims, locks implying perfect security, or
  third-party logos as endorsements.
- Accessibility: minimum 4.5:1 text contrast and readable at 320 px wide.
- Export: PNG, under 1 MB where practical.
- Alt text: “Humane Intelligence MCP — local-first, tamper-evident memory and
  governance for AI agents.”

Upload requires GitHub repository administration access and is not performed by
committing this specification.
